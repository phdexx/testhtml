Принципы организации обмена данными в системах ввода-вывода

Проблема согласования скоростей

Эффективная организация обмена данными напрямую влияет на общую производительность системы, поскольку скорость работы периферийных устройств, как правило, на несколько порядков ниже скорости работы процессора. Это несоответствие породило необходимость выработки специальных методов управления вводом-выводом. Выделяют три основных подхода:

  1. Программируемый ввод-вывод (polling).
  2. Ввод-вывод по прерываниям (Interrupt-Driven I/O).
  3. Прямой доступ к памяти — ПДП (DMA).

1. Программируемый ввод-вывод

Наиболее простой метод: процессор непрерывно опрашивает регистр состояния контроллера устройства (polling). На протяжении всего обмена ЦП занят и не может выполнять другие задачи.

Применение: простые встроенные системы и микроконтроллеры.

2. Ввод-вывод по прерываниям

Процессор инициирует операцию и переключается на другие задачи. Устройство по готовности формирует сигнал прерывания (IRQ). Контроллер прерываний (PIC) обеспечивает приоритизацию и маршрутизацию запросов.

Применение: клавиатуры, последовательные порты, сетевые карты.

3. Прямой доступ к памяти (DMA)

Наиболее производительный метод. Контроллер ПДП самостоятельно передаёт блоки данных между устройством и ОЗУ в обход процессора.

Алгоритм работы

  1. ЦП программирует контроллер ПДП (адрес буфера, размер, направление).
  2. Контроллер захватывает системную шину (Bus Request → Bus Grant).
  3. Данные передаются напрямую: устройство ↔ ОЗУ. ЦП свободен.
  4. По завершении контроллер формирует прерывание.

Режимы работы ПДП

  • Single transfer — одно слово за запрос шины.
  • Burst mode — весь блок за один захват.
  • Cycle stealing — компромисс: по одному циклу шины.
Применение: SATA, NVMe, USB 3.x, PCIe, GPU. NVMe поддерживает до 65 535 очередей команд.

Буферизация и кэширование

  • Буферизация — временное хранение данных, сглаживающее разницу скоростей.
  • Страничный кэш ОС — хранит востребованные блоки в ОЗУ.
  • Аппаратное кэширование — DRAM-буфер контроллера + SLC-кэш флеш-памяти.
